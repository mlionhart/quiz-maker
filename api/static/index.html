Help

Question types and grading

Pick a type for each question: Written, Multiple choice, True / False (write a statement and set whether it is true; the AI can fill in an explanation) or Select multiple (type the correct answers separated by | and add wrong answers; the student must tick every correct option and nothing else). For Written questions, the small button beside the type sets grading (hover it for details): Exact (must match the answer, no AI), Standard (AI: flexible wording, facts must be right) or Gist (AI: the main idea is enough). For AI grading the answer is optional: without one, the AI uses the quiz's source material, or else general knowledge.

Wrong answers and explanations

For multiple choice, type the wrong answers separated by | or leave them blank and use the AI fill button, which also writes a short explanation. When you save and something is missing, you are asked whether the AI should fill it in (it uses tokens), so nothing is spent without your say-so. The AI only fills blank fields and never changes what you typed, except that it adds wrong answers until there are 3. Clicking the type button flips between Written and Multiple choice; use its arrow for the other types.

Blank answers

If an answer is blank (Written or multiple choice), and you choose to let the AI fill it in, it drafts one (from the source material or general knowledge) and stops so you can check it before saving. Exact questions always need your own answer.

Source material (optional)

Notes or text this quiz is based on. For written questions with no answer, the AI grades against this.
