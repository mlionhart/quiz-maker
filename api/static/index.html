Help

Question types and grading

Pick a type for each question. For Written questions, the small button beside the type sets grading (hover it for details): Exact (must match the answer, no AI), Standard (AI: flexible wording, facts must be right) or Gist (AI: the main idea is enough). For AI grading the answer is optional: without one, the AI uses the quiz's source material, or else general knowledge.

Wrong answers and explanations

For multiple choice, type the wrong answers separated by | or leave them blank and use the AI fill button, which also writes a short explanation. Saving also fills in anything missing. The AI only fills blank fields and never changes what you typed, except that it adds wrong answers until there are 3.

Blank answers

If an answer is blank (Written or multiple choice), the AI drafts one (from the source material or general knowledge) and stops so you can check it before saving. Exact questions always need your own answer.

Source material (optional)

Notes or text this quiz is based on. For written questions with no answer, the AI grades against this.
